# Farthest facilitated probe for an individual participant

This exploratory analysis asks which sampled probe could be an
individual's farthest point with positive mean tactile facilitation.
It allows any shape across probes and includes the possibility that
none is facilitated. The data comprise 8,478 retained Audio–Tactile
and 4,192 retained tactile-only latencies from 40 participants. Each
participant contributes four phase-specific profiles and two profiles
averaging the phases equally within each condition.
[Specification](INDIVIDUAL_FACILITATION_SPECIFICATION.md)

## Observed endpoint and condition estimates

| Tactile-only reference | Estimable profiles | Single supported probe | No facilitation possible |
| --- | ---: | ---: | ---: |
| Pooled within condition and phase | 240/240 | 0 | 236 |
| Same nominal label | 238/240 | 1 | 237 |
| Exact matches under +500 ms | 240/240 | 0 | 239 |

The one localized profile was a Control-inhale cell at 100 cm
under same-label subtraction. It identifies the farthest tested
probe on either map. Removing that probe left every remaining
probe and no facilitation compatible. Pooled and cue-matched
references left that cell unresolved. In the cue-matched analysis,
the +500 ms working offset leaves only the 27 and 100 cm registered
probes with an exact tactile-only match. The two unavailable
same-label profiles required a Baseline variance from a bin
with fewer than two retained trials.

Across both maps, all **1,908 estimable paired contrasts** could
be undefined because at least one active profile allowed no
facilitated probe. Even conditional on each active profile
having a facilitated probe, every finite contrast interval
included zero. None of the 239 estimable equal-phase profiles
across the three references isolated a single probe. The separately estimated
[group endpoint](FACILITATION_EDGE_RESULTS.md) remains dependent
on the reference choice.

## Recovery and probe sensitivity

Each generator used the observed participant trial counts and
variances in 96 simulated datasets per reference. The generating
endpoint was compatible in at least 99.94% of the estimable
profile sets in each reference-by-generator combination. Neither
the 40 ms nor the 120 ms step yielded a single correct probe in
any of the 68,928 estimable profiles per step generator, across
references. The planted registered-scale condition difference
was +23 cm on the five-probe designs. Taking only the two exact
cue matches left the same planted endpoint of 27 cm in both
conditions. All estimable paired equal-phase condition sets
retained the planted difference in the step simulations.

Constant +120 ms facilitation across the observed range yielded
a single outermost probe in 6,180/23,040 pooled profiles,
986/22,848 same-label profiles and 2,115/23,040 exactly matched
profiles. A detectable outermost sampled endpoint can arise when
facilitation has no transition within the sampled range. The
observed sets use working t intervals within bins and support
statements conditional on retained trials. They are exploratory
across participants and reference choices.

The omitted-probe checks retain the supported states for each
reduced series. The endpoint rule makes no prediction at a deleted
probe. In the separate [held-probe comparisons](THRESHOLD_RESULTS.md#held-distance-prediction)
for trial means, the registered-axis isotonic fit improved on the
flat model under pooled subtraction (48.91 vs 50.47 ms RMSE for
individual profiles). The flat model scored best under same-label
subtraction (78.85 vs 84.43 ms for isotonic).

## Reproduction

Run `python -X utf8 analysis/boundary_methods/individual_facilitation.py`
from the repository root with the [pinned native environment](../../analysis/baseline_effects/requirements.txt).
The numerical bundle regenerated byte for byte. An independent check
compared the endpoint calculation with 96 linear programming fixtures,
recalculated all 720 full profile sets and 2,880 probe omissions, and
enumerated the compatible distances for all 1,920 paired bounds.
