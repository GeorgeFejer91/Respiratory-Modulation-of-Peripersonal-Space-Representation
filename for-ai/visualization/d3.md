## Approach and decision tree

D3 supplies data joins, scales, shape generators and layouts rather than a
finite menu of chart constructors. Bind approved records to SVG/HTML elements
or draw generated geometry on canvas. CSS can style SVG marks directly.

```text
Can the existing inline-SVG owner or Plot express the figure simply?
  Yes -> reuse it; do not add D3 merely because a gallery example exists.
  No -> choose the needed D3 building blocks:
    Numeric/categorical data -> scales + axes + shapes/selections.
    Distributions -> bins/quantiles; compute approved KDE separately if needed.
    Spatial density -> contour/density; neighborhood -> Delaunay/Voronoi.
    Geographic data -> geo projection/path.
    Hierarchy -> hierarchy + tree/cluster/partition/pack/treemap.
    Network -> force + links; circular flows -> chord.
    Pointer navigation -> brush/zoom/drag with keyboard alternatives.
Need a worked implementation? -> D3 Graph Gallery profile; match API version.
Need a Sankey? -> separate companion module or current owner; not in d3/d3 core.
Need 3D/volume? -> Plotly; D3 does not supply a built-in scientific 3D menu.
```

## Complete umbrella-module inventory at the pin

| Modules | Figure responsibility |
| --- | --- |
| `d3-array` | Binning, grouping, quantiles and other array operations |
| `d3-axis` | Cartesian axis guides |
| `d3-brush`, `d3-drag`, `d3-zoom` | Selections and navigation |
| `d3-chord` | Chord layout and ribbon geometry |
| `d3-color`, `d3-interpolate`, `d3-scale-chromatic` | Color, interpolation and palettes |
| `d3-contour` | Scalar contours and spatial density estimation |
| `d3-delaunay` | Triangulations and Voronoi geometry |
| `d3-dispatch` | Event coordination |
| `d3-dsv`, `d3-fetch` | Data parsing/loading; preserve existing project preparation |
| `d3-ease`, `d3-timer`, `d3-transition` | Animation timing and transitions |
| `d3-force` | Force-directed graph layouts |
| `d3-format`, `d3-time-format` | Tick/value/date formatting |
| `d3-geo` | Geographic paths, projections and spherical operations |
| `d3-hierarchy` | Tree, cluster, partition, pack and treemap layouts |
| `d3-path`, `d3-polygon` | Path construction and polygon geometry |
| `d3-quadtree` | Spatial indexing |
| `d3-random` | Random generators; never change actual measured data |
| `d3-scale` | Quantitative, ordinal and time encodings |
| `d3-selection` | DOM selection, joins, attributes and events |
| `d3-shape` | Lines, areas, arcs, pies, symbols, links and stacks |
| `d3-time` | Time intervals |

Typical compositions include scatter/bubble, line/step, area/stacked area,
histogram, box/violin/raincloud, interval/forest, heatmap, parallel coordinates,
network, hierarchy and maps. These require chart-specific code; the exhaustive
finite list above is modules, not a claim of native constructors for each plot.
Hexbin and Sankey examples can require companion packages outside that list.

## Integration checks

Keep joins stable by participant/group ID; sort ordered paths and break missing
segments. Choose interpolation deliberately: a smooth SVG path does not fit a
scientific model. Verify scales, all interval extents, zero and equal units.
Handle resize, label measurement, keyboard access and full-value downloads in
the existing UI owner. Canvas geometry needs a separate accessible data surface
and verified vector export strategy. Return to [shared rules](README.md).
